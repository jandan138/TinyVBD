三条路总对照：penalty / AVBD / IPC

从一根孤零零、压根不碰撞的 strand 出发，这本书把「接触」这件事讲了一整条线：10-3 的 log-barrier + 几何截断，11-1 的 penalty 与 AVBD ramp，再到整个 Part 12 的 IPC。现在是收线的时候了。这一节不引入任何新东西，只做一件事：把 penalty、AVBD、IPC 三条路并排放在一张表里，沿着六个维度逐项对照，然后诚实地告诉你——没有银弹，该怎么选。

六个维度的总对照表

三条路的差别，可以压进六个维度：接触能量怎么写、求解是局部还是全局、无穿透是保证还是逼近、摩擦怎么处理、Hessian 怎么对待、代价几何。把它们并排看，三条路的「人设」一下就清楚了。

接触能量 penalty 软能量：穿得越深、回推越大 penalty + augmented Lagrangian（$\lambda$ + ramp） interior-point log-barrier，定义在每对 surface primitive
求解范围 局部：累加进 $\mathbf f_i/\mathbf H_i$，per-vertex 下降 局部：VBD block descent + primal-dual 全局：每步一个稀疏 Newton 解

这张表读下来有一条清晰的脊梁：从左到右，无穿透从「不保证」走到「严格保证」，代价从「便宜局部」走到「昂贵全局」。penalty 和 AVBD 共享「局部 + 便宜 + 可并行」的体质；AVBD 额外维护 augmented Lagrangian 的 multiplier 与 penalty，把约束逼得更硬；IPC 则独自站在「全局 + 昂贵 + 严格保证」的另一端。

interactive三条路压向地面：最后再看一眼穿透深度
同一个物体压向地面：penalty 会陷进去，AVBD 逼得很近、但仍是渐进，IPC 始终停在面前——这就是「不保证 / 逼近 / 保证」三种承诺的样子。

怎么选：没有银弹

看完表你可能想问：那到底用哪条？答案是那句老实话——没有银弹，按场景选。三条路是一组取舍，不是高下排名。

  • 要实时、要并行、能容忍一点点穿透 → penalty 或 AVBD。它们便宜、可并行，正是 VBD 局部下降的强项；游戏、交互式仿真、机器人实时控制这类场景，速度和并行度压倒一切，AVBD 还能把硬约束逼得相当好。
  • 要可靠、要在极端接触下绝不穿帮、能接受离线算力 → IPC。大形变、极端压缩、致密接触、需要严格 intersection-free 保证的离线高质量仿真，IPC 的那笔「贵」买的就是这份别人给不出的鲁棒。
  • 介于两者之间 → 看你更怕什么。怕慢，往 penalty/AVBD 走；怕穿帮，往 IPC 走。这条天平上没有免费的午餐：你想要的「保证」越严，付的算力越多。
共享接触目标，不是同一个 barrier 或固定目标

三条路都要把接触反馈耦合进一个 time step，但数学对象不同：penalty 使用有限的软能量；AVBD 把接触写成约束，并逐轮更新 augmented-Lagrangian 的 $\lambda$ 与 penalty；IPC 使用 interior-point log-barrier，再用 CCD-filtered line search 保持可行。10.3 的局部 log-barrier 与 IPC barrier 有共同的能量建模来源，但「局部 + 几何截断」和「全局 + CCD 可行性」并不是同一个完整算法，更不能把 penalty 与 AVBD 也统称为同一个 barrier。

收线：共享 incremental dynamics / 能量-约束视角

从 Part 1 的变分欧拉，到 Part 3 的 block coordinate descent，到 Part 10 的接触、Part 11 的 AVBD，再到这一整篇 IPC，共同问题都是如何在一个 time step 内平衡惯性、弹性与接触。对 penalty 或 IPC 这样的 energy-based 路线，当前一步可以写成 incremental potential：

$$\mathbf x^{t+1} \,=\, \arg\min_{\mathbf x}\; G(\mathbf x),\qquad G(\mathbf x) \,=\, \underbrace{\tfrac{1}{2h^2}\|\mathbf x-\mathbf y\|_{\mathbf M}^2}_{\text{惯性}} \,+\, \underbrace{E_{\text{elastic}}(\mathbf x)}_{\text{弹性}} \,+\, \underbrace{E_{\text{contact}}(\mathbf x)}_{\text{penalty 或 barrier}}$$

在这条能量路线里，penalty 与 IPC 分别选择软能量和 log-barrier，并可用 per-vertex 下降或全局稀疏 Newton 求解。AVBD 不能只看成替换上式的 $E_{\text{contact}}$：它还维护 multiplier 与 penalty，每轮处理一份随这些量变化的 augmented-Lagrangian 子问题。整本书的接触主线由共同动力学目标闭合，但三条路不是同一个固定 $\min G(\mathbf x)$ 的三种写法。

从 TinyVBD 看 你早就握着这把钥匙

回到最开始那根 strand：它的 solve() 里只有惯性 + 弹簧，连接触项都没有。但正是从那根 strand 上，你学会了把变分动力学读成 $\min G(\mathbf x)$、读成 per-vertex 的 $\Delta\mathbf x_i = \mathbf H_i^{-1}\mathbf f_i$。这把钥匙可以直接打开 penalty / IPC 的能量路线；遇到 AVBD，还要再加上 KKT 与 augmented-Lagrangian 这把钥匙。共同视角让三条路线可比较，并不要求把它们说成同一个优化器。

这一节你要带走的

三句话：(1) 三条路沿六维度对照——penalty 软、局部、便宜、不保证；AVBD 用 augmented Lagrangian 逼近硬、局部、便宜可并行；IPC 用 interior-point barrier + CCD line search 严格保证、全局稀疏 Newton、贵，整张表的脊梁就是「无穿透越严、代价越贵」。(2) 没有银弹：要实时可并行、容忍微穿透就选 penalty/AVBD，要严格 intersection-free、能接受离线算力就选 IPC，按场景取舍而非排高下。(3) 三者共享把接触耦合进增量动力学的目标，但数学对象不同：penalty / IPC 可写接触能量，AVBD 每轮处理变化的 augmented-Lagrangian 子问题；共同主线不等于同一个固定 $\min G$。
