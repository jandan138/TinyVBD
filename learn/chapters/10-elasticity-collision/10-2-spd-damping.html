PSD clamp、SPD 总块与 Rayleigh damping

先把三个对象分开：原始元件 Hessian 的定性取决于材料模型与当前构型；把负特征值截到 0 得到的是 PSD clamp / projection；再加正定惯性项后，装配出的局部总块才可能成为 SPD。当前 Newton 对部分元件采用 elementwise PSD 作为 robustness strategy，但它不是所有 FEM 的前置条件，也不保证防反转或静态稳定。TinyVBD C++ 则直接用 QR 解 raw 局部系统并接受 full step；Newton/Warp 的 determinant heuristic 只筛显式求逆前的近奇异情形，不是下降验收。这一节把这些边界讲清，再接上 Rayleigh damping。

为什么当前实现选择元件级 PSD clamp

回忆 1.5：一根被压缩的弹簧在当前构型下有横向特征值 $k(1-l_0/l)<0$。这说明局部二次模型存在负曲率方向，但不自动证明 buckling；屈曲必须先有平衡，再结合外载、约束与允许扰动检查全局切线谱，见 14.3。同样，FEM 单元是否不定也必须按具体能量和构型判断，不能由「压缩」「tet」或「bending」标签直接决定。

在当前 stable Neo-Hookean membrane 实现里，面积项系数 $s=\lambda_\text{NH}(J_s-\alpha)$ 在某些压缩构型下为负，原始 per-vertex 块可能出现负曲率。Newton 选择在这类元件装配前构造 PSD 近似，避免该负曲率直接进入局部 Newton 模型。这是明确的工程取舍：可用 modified Cholesky、trust region、damped Newton 或 line search 替代或配合，而不是「所有 FEM 必须先投影」的定理。

membrane 的 PSD clamp：max(0, ·)

以 membrane 为例，Newton 的实现里那一步极其朴素。能量 $\psi=\frac{\mu}{2}(I_c-2)+\frac{\lambda}{2}(J_s-\alpha)^2$ 装配 per-vertex Hessian 时，面积项贡献一个标量系数 $s=\lambda_\text{NH}(J_s-\alpha)$；Newton 直接对它做一次下截断：

$$s_\text{clamp}=\max\!\big(0,\;\lambda_\text{NH}\,(J_s-\alpha)\big).$$

当 $s<0$ 时，$\max(0,\cdot)$ 把它夹到 0，得到这个 membrane per-vertex 块的 tight PSD clamp。这里的名字必须准确：最小特征值允许等于 0，所以修改后的块是半正定（PSD），不是正定（SPD）。装配后的 $\mathbf H_i$ 还包含惯性与其他元件贡献，不能只凭这一夹就断言总块 SPD。

particle_vbd_kernels.py
# --- Hessian (per-vertex 3x3, PSD-clamped) ---
# max(0, s) is the tight PSD clamp for the membrane per-vertex block.
s_clamp = wp.max(0.0, s)   # s = lmbd_nh * (J_s - alpha)
r = s_clamp * inv_J_s
c1 = lmbd_nh - r

手算一遍钳取：压缩元件的两个特征值

$\max(0,\cdot)$ 听着抽象，代两个特征值进去就一目了然。复用 1.5 那个弹簧 Hessian $\mathbf H_{aa}=k\big[\mathbf I-\frac{l_0}{l}(\mathbf I-\frac{\mathbf d\mathbf d^\top}{l^2})\big]$——它有两类特征向量，特征值闭式可写：沿弹簧方向 $\hat{\mathbf d}$ 的是 $k$，垂直方向的是 $k(1-l_0/l)$。取一个被压缩的元件（当前长 $l<l_0$，比如 $l_0/l=1.25$），并把 $k$ 归一到 $1$ 让数字干净：

$$\lambda_\parallel=k=+1\ (\text{沿 }\hat{\mathbf d}),\qquad \lambda_\perp=k\Big(1-\frac{l_0}{l}\Big)=1\times(1-1.25)=-0.25\ (\text{垂直 }\hat{\mathbf d})$$

沿弹簧方向的曲率是 $+1$；垂直方向因为被压缩而翻负（$-0.25$），所以当前局部 Hessian 不定。这只是负曲率示例，不是单凭一个元件就宣布结构屈曲。raw Newton 方向可能因此上坡；PSD clamp 的谱图像，是把这个负特征值截到 0：

$$\lambda_\perp^{\text{clamp}}=\max(0,\,-0.25)=0\quad\Rightarrow\quad \text{特征值变成}\ \{+1,\ 0,\ 0\}\ (\text{半正定})$$

钳完这块 Hessian 只剩半正定（最小特征值 $0$）。在这个简化例子里，若顶点质量为正且其余装配贡献也不引入负曲率，惯性项 $\frac{m}{h^2}\mathbf I$ 会给每个方向加一个严格为正的底。沿用参数 $m=1,\ h=\tfrac{1}{60}$，惯性底是 $\frac{m}{h^2}=3600$，于是合成后的特征值是

$$\{+1,0,0\}+3600\cdot\{1,1,1\}=\{3601,\ 3600,\ 3600\}\;>\;0$$

这个简化总块的三个特征值全严格为正，因此 $\mathbf H_i$ 是 SPD；在 $\mathbf f=-\nabla G$ 的符号约定下，它给出下降方向。但这仍不保证 $\alpha=1$ 的 full step 降低非线性 $G$。两道一起看：PSD clamp 把 $-0.25$ 截到 $0$，正定惯性项才把这个例子的局部总块抬成 SPD。这组数字只说明术语与机制，不证明每个模型都需要 elementwise clamp，也不证明惯性在任意参数下都足够。

这组特征值是自洽示例，量级随材料/单位变

$+1/-0.25$、惯性底 $3600$ 是为手算挑的干净自洽数（$k$ 归一到 $1$、用 $m=1,h=\tfrac1{60}$）。真实 membrane 的谱随材料模型、构型、Lamé 参数与网格尺度变化。值得记的是这组示例中的术语链：负曲率 → $\max(0,\cdot)$ 截到 0 得 PSD → 正定惯性加入后局部总块才可能 SPD；它不是对所有构型的统一因果公式。

interactive拖动弹簧，看垂直特征值怎么翻负
把弹簧拖到压缩（当前长 < rest 长），看垂直方向的特征值由正转负——正是上面手算的 $-0.25$ 那个分量的现场版。它展示的是当前构型的局部负曲率；可用 PSD/modified Hessian 构造稳健方向，但不能仅凭这张局部谱图判定 buckling。

stable Neo-Hookean：让 rest state 无应力

上面那个 $\lambda_\text{NH}$ 不是随手写的 Lamé 参数。Newton 按 Smith 2018 §3.4 的 stable Neo-Hookean 约定，把用户给的 Lamé 参数换算成 NH 能量里真正用的参数：

$$\mu_\text{NH}=\mu_\text{Lamé},\qquad \lambda_\text{NH}=\lambda_\text{Lamé}+\mu_\text{Lamé}.$$

再配上 $\alpha=1+\mu_\text{NH}/\lambda_\text{NH}$，这套约定保证一件要紧的事：在 rest configuration（$F$ 为等距、$J_s=1$）下能量的梯度恰好为零，也就是静止状态无应力（stress-free）。否则材料一放进场景就自己鼓一下、缩一下，rest 形状都站不稳。这是 production 弹性必须做对、而 strand 那种纯 Hookean 弹簧天然不需要操心的细节——弹簧的 $E=\frac12 k(l-l_0)^2$ 在 $l=l_0$ 处梯度本就为零。

PSD clamp 不是防翻面或静态稳定证明

原始总块不定时，raw Newton 方向可能上坡；elementwise PSD clamp 是处理方向的一种办法，modified Cholesky、trust region 与 damped Newton 也能修改二次模型，line search 则负责只接受实际下降的步长。把负曲率截掉并不保证 full step 单调、$J>0$ 或 inversion-free，也不证明静态切线稳定；它还可能抹掉真实临界模态，让算法停在本应屈曲的对称分支。防反转需要 barrier 的有效定义域与可行步长，静态稳定和 buckling 应检查未 clamp 的物理切线矩阵。

从 TinyVBD 看 C++ QR 与 Warp determinant 是不同实现细节

TinyVBD main.cpp 装配原始局部 $\mathbf H$ 后，直接执行 h.colPivHouseholderQr().solve(f)，再用 vertex += dx 接受 raw full step；代码里没有 determinant guard、PSD 修改或 line search/能量验收。Newton/Warp 的另一条路径在显式求逆前检查 abs(det(H)) > 1e-8，那只是尺度相关的近奇异 heuristic：不定矩阵也可能有很大的 determinant，所以它不判断 SPD，更不保证下降。当前 Newton 的 elementwise PSD clamp 又是独立的模型稳健化步骤，不能把这些不同实现细节拼成 TinyVBD 的联合稳定保证。

Rayleigh damping：D = kd·ke

稳定性还有另一面：耗散。TinyVBD 对阻尼的处理很轻——弹簧带一个 damping 项，本质是把速度相关的耗散塞进力里，简单直接。Newton 走的是更规整的 Rayleigh damping 约定：阻尼系数不是一个独立的物理量，而是正比于刚度——

$$D=k_d\cdot k_e,$$

其中 $k_e$ 是元件刚度，$k_d$ 是一个无量纲的 Rayleigh 系数（solver_vbd.py 注明 VBD 把 kd 解释为 dimensionless Rayleigh coefficient）。这样写有两个好处：一是阻尼自动随刚度缩放，硬的地方阻尼也大、软的地方阻尼也小，不用为每种材料单独标定一个绝对阻尼；二是 $k_d$ 无量纲，跨场景搬运不会因单位变化而错。membrane 与 volumetric 各自有对应的 Frobenius/trace 形式耗散项接进这套约定。

无量纲约定的一个反作用力

正因为 $D=k_d\cdot k_e$ 把阻尼绑在刚度上，一个看起来不大的 $k_d$ 配上很硬的 $k_e$ 也可能耗散过猛。Newton 文档就专门提醒：某些 joint limit 的默认 kd（如 $10^1$）在这套 Rayleigh 约定下会产生 excessive damping，用到时要显式调小。这是「约定优雅」换来的代价——你得记住它是相对刚度的系数，不是绝对阻尼值。

这一节你要带走的

三句话：(1) Hessian 的定性取决于模型与构型；当前 Newton 对 membrane 使用 $s_\text{clamp}=\max(0,\lambda_\text{NH}(J_s-\alpha))$ 这种 elementwise PSD clamp，截到 0 只得到半正定块，加入正定惯性后局部总块才可能 SPD。(2) 这是一种 robustness strategy，不是 FEM 前置条件；modified Cholesky、trust region、damped Newton 与 line search 各有替代或配套角色，投影也不保证 inversion-free/静态稳定并可能隐藏物理屈曲。(3) stable Neo-Hookean 用 $\lambda_\text{NH}=\lambda_\text{Lamé}+\mu_\text{Lamé}$ 保证 rest state 无应力，阻尼则用无量纲 Rayleigh 约定 $D=k_d\cdot k_e$。
