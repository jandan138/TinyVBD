每个顶点的 3×3 牛顿步：f_i 与 H_i

前两节给出了每个顶点的 raw Newton 候选 $\Delta\mathbf x_i=\mathbf H_i^{-1}\mathbf f_i$，并证明了只移动该顶点时 $\Delta G=\Delta G_i$。后一个等式不保证候选步下降：方向还取决于 $\mathbf H_i$ 的谱，full step 还可能走过头。现在把 $\mathbf f_i$ 和 $\mathbf H_i$ 彻底拆开，看清这个便宜的 $3\times3$ 候选步究竟包含什么。

两个组件：惯性 + 相邻弹簧

$\mathbf f_i$ 是局部能量 $G_i$ 的负梯度，$\mathbf H_i$ 是它的 Hessian。$G_i$ 由两部分组成——惯性项和相邻弹簧项——所以 $\mathbf f_i$、$\mathbf H_i$ 自然也各分两块：

$$\mathbf f_i = \underbrace{-\frac{m_i}{h^2}(\mathbf x_i-\mathbf y_i)}_{\text{惯性力}} \;-\; \sum_{j\in\mathcal F_i}\frac{\partial E_j}{\partial \mathbf x_i}$$
$$\mathbf H_i = \underbrace{\frac{m_i}{h^2}\mathbf I}_{\text{恒正定}} \;+\; \sum_{j\in\mathcal F_i}\frac{\partial^2 E_j}{\partial\mathbf x_i^2}$$

第一块——惯性项——好理解：它把顶点往预测位置 $\mathbf y_i$ 拉，力的大小正比于偏离量，Hessian 是各向同性的 $\frac{m_i}{h^2}\mathbf I$，一个永远正定的对角块。质量越大、时间步越小，这块越「硬」，把顶点摁在 $\mathbf y_i$ 附近越紧。第二块——相邻弹簧的求和——才是有意思的地方，下面展开。

从相邻边装配：vertAdjacentEdges

$\mathcal F_i$ 这个「与 $i$ 相邻的 force elements」在代码里就是 vertAdjacentEdges[i]——一个边 id 列表，记录哪些弹簧的端点之一是顶点 $i$。在一根普通 strand 里，中间顶点 $i$ 邻接两条边（连向 $i-1$ 和 $i+1$）；若开了 skip spring（近似弯曲），还会多挂一两条连向 $i\pm2$ 的边。装配 $\mathbf f_i$、$\mathbf H_i$ 就是：先放好惯性那一块，再遍历这个列表，把每条相邻弹簧贡献的力和 Hessian 累加上去：

main.cpp · solve() 内层
// 惯性块先放好
f = vertexMass(iV) * (inertia.col(iV) - vertex(iV)) * dtSqrReciprocal;
h += vertexMass(iV) * dtSqrReciprocal * Mat3::Identity();

// 遍历相邻边，逐条累加
for (iNeiE : vertAdjacentEdges[iV]) {
    int edgeId = vertAdjacentEdges[iV][iNeiE];
    IdType v1 = edges[edgeId][0], v2 = edges[edgeId][1];
    Vec3 diff = mVertPos.col(v1) - mVertPos.col(v2);   // d = x_v1 - x_v2
    FloatingType l  = diff.norm();                       // 当前长度
    FloatingType l0 = orgLengths(edgeId);                // rest length
    FloatingType k  = edgesStiffness[edgeId];
    h += k * (Mat3::Identity() - (l0/l) * (Mat3::Identity() - diff*diff.transpose()/(l*l)));
    if (v1 == iV) f += (k * (l0 - l) / l) * diff;        // 力的符号取决于 iV 是哪端
    else          f -= (k * (l0 - l) / l) * diff;
}

每条边只让 $\mathbf f_i$、$\mathbf H_i$ 各加一项——这正是上面求和式 $\sum_{j\in\mathcal F_i}$ 的逐项实现。4.3 会把 solve() 整段逐行再走一遍。

塞进弹簧的力与 Hessian

那「每条边贡献什么」？这正是 1.5 推过的弹簧公式。记弹簧两端为 $a,b$，$\mathbf d=\mathbf x_a-\mathbf x_b$，当前长度 $l=\lVert\mathbf d\rVert$，rest length $l_0$，刚度 $k$。能量、力（对端点 $a$）、Hessian 块分别是：

$$E=\tfrac12 k(l-l_0)^2,\qquad \mathbf f_a = k\,\frac{l_0-l}{l}\,\mathbf d,\qquad \mathbf H_{aa}=k\Big[\mathbf I-\frac{l_0}{l}\Big(\mathbf I-\frac{\mathbf d\mathbf d^\top}{l^2}\Big)\Big]$$

把这两个表达式比对上面代码里的 f += (k*(l0-l)/l)*diff 和 h_1_1 = k*(I - (l0/l)*(I - diff·diffᵀ/(l·l)))，它们一字不差。当顶点 $i$ 处在弹簧的另一端（$b$ 端）时，力反号——代码里 v1 == iV 的判断就是在挑符号。Hessian 块对两端是同一个 $\mathbf H_{aa}$（这个对称弹簧的「自块」对 $a$、对 $b$ 形式相同），所以直接累加即可。

弹簧 Hessian 可不定；惯性偏置不是无条件修复

对 $l>0$，$\mathbf H_{aa}$ 沿弹簧方向的特征值是 $k$，两个垂直特征值是 $k(1-l_0/l)$。压缩时它们为负，而且没有有限下界：当 $l\to0^+$ 时 $k(1-l_0/l)\to-\infty$；到 $l=0$，长度范数不可微，上面的力与 Hessian 公式本身就不再定义。惯性块 $\frac{m_i}{h^2}\mathbf I$ 会把三个特征值统一向正方向平移，却不能对任意压缩、刚度和时间步保证 $\mathbf H_i$ 为 SPD。若合成 $\mathbf H_i$ 仍不定，raw Newton 可能朝上坡；若 full step 太大，即便 SPD 也可能让真实能量上升。数值与接受条件的区别见 3.6，负曲率的深挖见 Part 14。

手算一遍：一个中间顶点的完整装配

说了这么多「小到能手算」，那就真算一遍。我们取一根 strand 中间的顶点 $i$，用全书共享的那组参数，把 $\mathbf H_i$、$\mathbf f_i$ 一格一格填出来，最后解出 $\Delta\mathbf x_i$。坐标特意选得干净，让每一步都能用心算复核。

这是为讲解构造的自洽示例

下面的具体数字（坐标、$\mathbf y_i$）是为了把装配过程算给你看而精心挑的，示意性地展示「惯性块 + 两条压缩弹簧」怎么拼成一个 $3\times3$。结构（惯性块提供正偏置、压缩弹簧贡献负的垂直特征值、对称力相消）是真的；具体小数不对应任何真实帧。

布置：坐标与参数

顶点 $i$ 当前在原点，左右各有一个邻居，两条弹簧都沿 $x$ 轴、且都被压到原长的一半：

$$\mathbf x_i=(0,0,0),\quad \mathbf x_{\text{左}}=(-0.5,0,0),\quad \mathbf x_{\text{右}}=(0.5,0,0)$$
$$m_i=1,\quad h=\tfrac1{60}\ \Rightarrow\ \frac{m_i}{h^2}=3600;\qquad k=100,\ l_0=1,\ l=0.5\ \Rightarrow\ \frac{l_0}{l}=2$$

惯性目标取 $\mathbf y_i=(0,-0.01,0)$——顶点这一步「想」往下掉一点点（重力把惯性碗底压到了 $x_i$ 下方）。

第 1 块：惯性

按 $\mathbf f_i\mathrel{+}=\frac{m_i}{h^2}(\mathbf y_i-\mathbf x_i)$、$\mathbf H_i\mathrel{+}=\frac{m_i}{h^2}\mathbf I$：

$$\mathbf f_i^{\text{惯}}=3600\cdot(0,-0.01,0)=(0,-36,0),\qquad \mathbf H_i^{\text{惯}}=3600\,\mathbf I=\mathrm{diag}(3600,3600,3600)$$

第 2 块：两条弹簧（$\mathbf d$、外积、± 号）

左弹簧（端点 $v_1=i,\ v_2=\text{左}$）：$\mathbf d=\mathbf x_i-\mathbf x_{\text{左}}=(0.5,0,0)$，$l=\lVert\mathbf d\rVert=0.5$。外积归一化：

$$\frac{\mathbf d\mathbf d^\top}{l^2}=\frac{1}{0.25}\begin{pmatrix}0.25&0&0\\0&0&0\\0&0&0\end{pmatrix}=\mathrm{diag}(1,0,0)$$

代进弹簧 Hessian $\mathbf H_{aa}=k\big[\mathbf I-\frac{l_0}{l}(\mathbf I-\frac{\mathbf d\mathbf d^\top}{l^2})\big]$。内层 $\mathbf I-\mathrm{diag}(1,0,0)=\mathrm{diag}(0,1,1)$，乘 $\frac{l_0}{l}=2$ 得 $\mathrm{diag}(0,2,2)$，再被 $\mathbf I$ 减：

$$\mathbf H_{aa}^{\text{左}}=100\cdot\big[\mathrm{diag}(1,1,1)-\mathrm{diag}(0,2,2)\big]=100\cdot\mathrm{diag}(1,-1,-1)=\mathrm{diag}(100,-100,-100)$$

这正是共享参数集预告的 $\lambda_\parallel=100$（沿弹簧的 $x$ 方向，硬）、$\lambda_\perp=k(1-l_0/l)=100(1-2)=-100$（垂直方向，因压缩而为负，不定）。弹簧力按 $\mathbf f=k\frac{l_0-l}{l}\mathbf d$，系数 $100\cdot\frac{1-0.5}{0.5}=100$：

$$\mathbf f^{\text{左}}=100\cdot(0.5,0,0)=(50,0,0)\quad(\text{因 }v_1=i,\ \text{取}+\text{号})$$

右弹簧（端点 $v_1=\text{右},\ v_2=i$）：$\mathbf d=\mathbf x_{\text{右}}-\mathbf x_i=(0.5,0,0)$——和左边形状相同，所以 Hessian 块一模一样 $\mathrm{diag}(100,-100,-100)$（Hessian 不分端点，见上一节的 callout）。但力要反号：现在 $i$ 是 $v_2$，代码走 else 分支 $\mathbf f\mathrel{-}=\ldots$，而 $\mathbf d$ 指向 $i$ 的反方向，合起来：

$$\mathbf f^{\text{右}}=-100\cdot(0.5,0,0)=(-50,0,0)$$
两条力恰好相消——这正是 ± 号在干活

$\mathbf f^{\text{左}}+\mathbf f^{\text{右}}=(50,0,0)+(-50,0,0)=(0,0,0)$。对称压缩下，左右弹簧把 $i$ 往两边推的力大小相等、方向相反，净弹簧力为 0。这不是巧合，正是 ± 号（v1==iV 的判断）保证了「同一根弹簧从不同端看，力反向」。

装配 $\mathbf H_i$ 与 $\mathbf f_i$

把惯性块和两条弹簧块全加起来（本例都是对角阵，逐元素相加即可）：

$$\mathbf H_i=\underbrace{\mathrm{diag}(3600,3600,3600)}_{\text{惯性}}+\underbrace{2\times\mathrm{diag}(100,-100,-100)}_{\text{两条弹簧}}=\mathrm{diag}(3800,\,3400,\,3400)$$
$$\mathbf f_i=\underbrace{(0,-36,0)}_{\text{惯性}}+\underbrace{(0,0,0)}_{\text{弹簧（相消）}}=(0,-36,0)$$

注意垂直方向：单看弹簧是 $-200$（两条各 $-100$，负的，不定），但本例惯性块的 $+3600$ 一加，整体变成 $+3400>0$。这只证明这组参数下合成 $\mathbf H_i$ 为 SPD、Newton 候选是下降方向；更强压缩、更大刚度或更大时间步都可能让惯性偏置压不住负曲率，不能把这个算例外推成普遍保证。

解这个 3×3

$\mathbf H_i$ 是对角阵，求逆就是逐元素取倒数，$\Delta\mathbf x_i=\mathbf H_i^{-1}\mathbf f_i$ 直接逐分量除：

$$\Delta\mathbf x_i=\Big(\frac{0}{3800},\ \frac{-36}{3400},\ \frac{0}{3400}\Big)=(0,\,-0.01059,\,0)$$

读出来：这一步把顶点 $i$ 往下挪了约 $0.0106$，方向正是惯性想要的 $-y$。它没挪满 $\mathbf y_i$ 的 $-0.01$ 吗？——其实略超了一点点（$-0.0106$ vs $-0.01$），因为压缩的弹簧在垂直方向是「软」的（有效刚度只有 $3400$ 而非纯惯性的 $3600$），对 $y$ 方向的束缚比纯惯性更松。一步牛顿就这么解完了——整个过程没碰一个大稀疏矩阵，全是 $3\times3$ 的逐元素算术。

那个 3×3 求解：很小，但各 block 仍然耦合

装配完，$\mathbf f_i$ 是一个 $3\times1$ 向量，$\mathbf H_i$ 是一个 $3\times3$ 矩阵，求位移就是解

$$\mathbf H_i\,\Delta\mathbf x_i=\mathbf f_i\quad\Longrightarrow\quad \Delta\mathbf x_i=\mathbf H_i^{-1}\mathbf f_i$$

这是整套算法里最重的局部线性代数，而它不过是个 $3\times3$。TinyVBD 用 Eigen 的 h.colPivHouseholderQr().solve(f) 解 $\mathbf H_i\Delta\mathbf x_i=\mathbf f_i$，省掉了全局稀疏组装与分解。QR 只负责求这个线性系统的数值解；它不检查 $\mathbf H_i$ 是否 SPD，也不保证 $\Delta\mathbf x_i$ 是下降方向或 $\alpha=1$ 会降低能量。

这些小系统也不是 $N$ 个互不相干的问题。$\mathbf f_i$、$\mathbf H_i$ 都读取邻居位置和共享元件；顶点 $i$ 一写回，后续顶点的局部系统就随之改变。VBD 做的是同一个耦合非线性系统的顺序局部解，用 Gauss-Seidel 在 block 间传播信息，而不是把物理系统拆成互不作用的 $N$ 份。（在 strand、布或体网格中，只要每块仍取单个 3D 顶点，局部矩阵都是 $3\times3$。）

把节奏再走一遍

于是顶点 $i$ 的一次处理可以分成：

  1. 惯性块：$\mathbf f_i\mathrel{+}=\frac{m_i}{h^2}(\mathbf y_i-\mathbf x_i)$，$\mathbf H_i\mathrel{+}=\frac{m_i}{h^2}\mathbf I$。
  2. 遍历 vertAdjacentEdges[i]：每条边按 1.4 的公式累加弹簧力到 $\mathbf f_i$、弹簧 Hessian 到 $\mathbf H_i$（注意符号取决于 $i$ 是哪端）。
  3. 解 $3\times3$，得到 raw 候选 $\mathbf p_i=\mathbf H_i^{-1}\mathbf f_i$。
  4. 完整求解器可检查方向并用局部 backtracking/Armijo 选择 $\alpha$；TinyVBD 的精简 C++ 不做这一步，直接取 $\alpha=1$。
  5. 就地更新：$\mathbf x_i\mathrel{+}=\alpha\mathbf p_i$，让下一个顶点读到新位置（Gauss-Seidel）。

上一节那个 vbd-sweep 部件里，左侧每步显示的 $\mathbf f_i$、$\mathbf H_i$、$\Delta\mathbf x_i$，就是装配与 raw 候选的实时数值；它展示当前参数下的结果，不替代接受条件。

这一节你要带走的

三句话：(1) $\mathbf f_i=\frac{m_i}{h^2}(\mathbf y_i-\mathbf x_i)-\sum_{j}\partial E_j/\partial\mathbf x_i$，$\mathbf H_i=\frac{m_i}{h^2}\mathbf I+\sum_j\partial^2 E_j/\partial\mathbf x_i^2$，由惯性块与相邻弹簧块装配；(2) 压缩弹簧的横向特征值在 $l\to0^+$ 时趋于 $-\infty$，$l=0$ 处公式不可微，惯性只提供正偏置而非无条件 SPD；(3) 每个 $3\times3$ 解只是耦合系统中的顺序局部候选，QR 不负责下降验收。
