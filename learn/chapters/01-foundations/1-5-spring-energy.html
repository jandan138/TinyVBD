弹簧的能量、力与 Hessian

前面 $E(\mathbf x)$ 一直是个抽象符号。这一节把它落到一根真实的 Hookean 弹簧上：写出能量、求出力、再求出 Hessian——然后撞见一个关键事实：弹簧被压缩时，Hessian 在横向的特征值会变负、矩阵变得不定。这是受压构型的局部负曲率，也是后续屈曲分析的一项原料，但它本身还不是完整的屈曲判据。

一根弹簧的能量 E(x)

取一根弹簧，两端点 $\mathbf x_a,\mathbf x_b$，rest length 为 $l_0$，stiffness 为 $k$。记方向向量与当前长度

$$\mathbf d=\mathbf x_a-\mathbf x_b,\qquad l=\lVert\mathbf d\rVert.$$

Hookean 弹簧的能量就是「拉伸量的平方」乘以半刚度：

$$E=\tfrac12 k\,(l-l_0)^2.$$

它在 $l=l_0$（恰好等于 rest 长度）时为零、为最小，往两边——无论拉长还是压短——都涨上去。把整根 strand 上所有弹簧的 $E$ 加起来，就是 1.2 那个 $G(\mathbf x)$ 里的弹性势能项。下面这根弹簧的全部物理，都从这一行长出来。

力 = 能量的负梯度

力是能量对位置的负梯度 $\mathbf f=-\partial E/\partial\mathbf x_a$。链式法则：$\partial E/\partial l=k(l-l_0)$，而 $\partial l/\partial\mathbf x_a=\mathbf d/l$（单位方向）。合起来，作用在端点 $a$ 上的力是

$$\mathbf f_a=-\,\frac{\partial E}{\partial\mathbf x_a}=k\,\frac{l_0-l}{l}\,\mathbf d,$$

端点 $b$ 取负号（作用力与反作用力）。读一下符号：当 $l>l_0$（被拉长），$l_0-l<0$，力沿 $-\mathbf d$，把 $a$ 往 $b$ 拉回去；当 $l<l_0$（被压短），$l_0-l>0$，力沿 $+\mathbf d$，把 $a$ 往外推开。弹簧总想回到 rest 长度，符合直觉。这一行正是 solve() 里 ±stiffness*(l0-l)/l*diff 的来历。

Hessian：gradient 对位置的 Jacobian

记能量 gradient 为 $\mathbf g_a=\partial E/\partial\mathbf x_a=-\mathbf f_a$。Hessian 是 gradient 的 Jacobian，$\mathbf H_{aa}=\partial\mathbf g_a/\partial\mathbf x_a$；因此它等于 force Jacobian 的负号：$\mathbf H_{aa}=-\partial\mathbf f_a/\partial\mathbf x_a$。VBD 的局部 Newton 模型使用的是这个能量 Hessian，不能把两种矩阵混名。对端点 $a$ 的 $3\times3$ 自块（二维里是 $2\times2$），得到

$$\mathbf H_{aa}=k\Big[\mathbf I-\frac{l_0}{l}\Big(\mathbf I-\frac{\mathbf d\,\mathbf d^\top}{l^2}\Big)\Big].$$

这个式子初看吓人，其实结构很清楚。$\frac{\mathbf d\mathbf d^\top}{l^2}$ 是「沿弹簧方向」的投影矩阵，$\mathbf I-\frac{\mathbf d\mathbf d^\top}{l^2}$ 则投到横向子空间。因此 $\mathbf H_{aa}$ 只有两个不同的特征值：一个沿弹簧轴，另一个属于整个横向子空间；在 3D 中横向特征值的重数为 2。以上方向公式要求 $l>0$；若 $l=0$ 且 $l_0>0$，方向、gradient 与 Hessian 都没有经典定义。投影形式与零长度边界的完整推导见 14-2。

两个 distinct eigenvalues：3D 横向重数为 2

把 $\mathbf H_{aa}$ 分别作用在「沿 $\mathbf d$」和「垂直 $\mathbf d$」的方向上，特征值一眼就读出来：

  • 沿弹簧方向：垂直投影那项为零，剩 $\mathbf H_{aa}\mathbf d=k\,\mathbf d$，特征值 $=k$。永远是正的，且就等于刚度——沿轴向的局部曲率恒为正。
  • 垂直弹簧方向：沿弹簧投影那项为零，特征值 $=k\big(1-\tfrac{l_0}{l}\big)$。它的符号取决于 $l$ 和 $l_0$ 的大小：拉伸（$l>l_0$）时为正；恰好 rest（$l=l_0$）时为零；压缩（$l<l_0$）时 $\frac{l_0}{l}>1$，于是这个特征值变负。
$$\lambda_{\parallel}=k\;(>0\ \text{恒成立}),\qquad \lambda_{\perp}=k\Big(1-\frac{l_0}{l}\Big)\;\xrightarrow{\,l<l_0\,}\;\text{负}.$$

轴向特征值为正、横向特征值为负，意味着受压构型下 $\mathbf H_{aa}$ 不再正定，而是indefinite（不定）。这个负值只说明固定另一端时，当前构型附近存在一条横向降能方向；它是屈曲分析会用到的局部曲率原料。只有把外载、约束与其他元件都计入总势能，先满足驻点条件，再在允许方向上发现失稳，才可以谈 buckling。严格边界见 14-3。

退一步：驻点处的碗 vs 马鞍

我们一路在说「正定 / 不定」，但二阶曲率要在正确前提下解释。Hessian 描述能量面在当前点沿各主方向怎样弯；要用它判断局部极小或鞍点，必须先有 $\nabla E=0$。有约束时，还只能检查满足约束的允许方向（一般是约束切空间中的 reduced/Lagrangian Hessian）：

  • 驻点处，所有允许方向曲率都为正。这是严格局部极小的二阶充分条件；无约束时就是 $H\succ0$。
  • 驻点处，同时存在允许的正、负曲率方向。这时才可把该点判为鞍点；若 $\nabla E\ne0$，一阶坡度仍占主导，不能只凭不定 Hessian 给当前点贴上「鞍点」标签。
  • 出现零特征值。这只表示二阶模型在该方向信息不足，不代表能量恒定或存在平底。例如 $E(x)=x^4$ 在 $x=0$ 的 gradient 与 Hessian 都为零，原点仍是严格局部极小；此时必须看高阶项或对称性。

对最小化而言，$H\succ0$ 会使 $p=-H^{-1}g$ 成为下降方向；$H$ 不定时，raw Newton 方向可能反而满足 $g^\top p>0$。这说的是优化方向，不是说非驻点已经物理失稳。下面先用二次模型看曲率符号，再回到真实弹簧。

代码对照：这就是 solve() 里的 h_1_1

上面那个 $\mathbf H_{aa}$ 不是黑板演算，它一字不差地躺在 TinyVBD 的 solve() 里：

main.cpp
Vec3 diff = strand.mVertPos.col(v1) - strand.mVertPos.col(v2);   // d = x_a - x_b
FloatingType l  = diff.norm();                                   // l = |d|
FloatingType l0 = strand.orgLengths(edgeId1);                    // rest length l0
Mat3 h_1_1;
h_1_1 = stiffness_ * (Mat3::Identity()
        - (l0 / l) * (Mat3::Identity() - diff * diff.transpose() / (l * l)));
h += h_1_1;

逐项对得上：diff 是 $\mathbf d$，l 是 $l$，l0 是 $l_0$，diff*diff.transpose()/(l*l) 就是 $\frac{\mathbf d\mathbf d^\top}{l^2}$。整句 h_1_1 = stiffness*(I - (l0/l)*(I - dd^T/l^2)) 与公式 $\mathbf H_{aa}=k[\mathbf I-\frac{l_0}{l}(\mathbf I-\frac{\mathbf d\mathbf d^\top}{l^2})]$ 完全一致。4.3 会把 solve() 整段逐行读透；14-2 则给出不跳步的 projector 推导。这里你只需认出：那一行真的可能给你一个不定的能量 Hessian。

从 GAMES103 看 这就是隐式积分要做「SPD 投影」的原因

组装出的 Hessian（或 $M-h^2\nabla\mathbf f$）不正定时，Newton 方向可能不是下降方向。Modified/PSD Hessian、damping 或 trust region 先负责把方向/模型修好；line search 再沿下降方向选择步长。若方向本来上坡，单纯把步长缩小不能保证下降。这三件事的分工见 14-3。

惯性项 m/h²·I 是怎么帮上忙的

好消息是：VBD 每个顶点真正要解的，不是孤零零的弹簧 Hessian，而是它加上惯性项之后的局部 Hessian（见 1.4）：

$$\mathbf H_i=\underbrace{\frac{m_i}{h^2}\mathbf I}_{\text{恒正定}}+\sum_{j}\mathbf H_{aa}^{(j)}.$$

惯性项 $\frac{m_i}{h^2}\mathbf I$ 是各向同性的正定矩阵，因此把整个弹性 Hessian 和的每个特征值统一加上 $\frac{m_i}{h^2}$。下面的 $\frac{m_i}{h^2}+k(1-l_0/l)$ 只针对单弹簧，或若干共轴、可同时对角化的教学例子；一般不同方向弹簧的 Hessian 不共享特征向量，应先对总和求谱。若偏置把局部总 Hessian 顶回正定，局部 Newton 方向就是下降方向；但这只正则化当前时间步的增量目标，不代表静态弹性系统已经稳定。

代真数字算一遍：偏置救得回软弹簧，救不回硬弹簧

把上面的符号换成数字，「不定」和「偏置非万能」就从一句话变成两行算术。取一根教学用小弹簧 $k=100$、$l_0=1$，把它压缩到 $l=0.5$（压成 rest 长度的一半）。先读两个特征值：

$$\lambda_\parallel=k=100\ (>0),\qquad \lambda_\perp=k\Big(1-\frac{l_0}{l}\Big)=100\Big(1-\frac{1}{0.5}\Big)=100\,(1-2)=-100.$$

横向特征值 $\lambda_\perp=-100<0$——孤零零的弹簧 Hessian 确实有一条负横向曲率。现在加惯性偏置。用共享参数集的轻顶点：$h=1/60$、$m=1$，于是 $\frac{m}{h^2}=3600$。进入求解的有效横向特征值是

$$\frac{m}{h^2}+\lambda_\perp=3600+(-100)=3500\ (>0).$$

$3500>0$——偏置轻松把负的顶回正，局部二次模型重新凸，Newton 方向成为下降方向。软弹簧这关，惯性项一手包办。但把同一根弹簧换成 TinyVBD 默认的硬弹簧 $k=10^8$（同样压到 $l=0.5$），横向特征值变成

$$\lambda_\perp=10^8\,(1-2)=-10^8,\qquad \frac{m}{h^2}+\lambda_\perp=3600-10^8\approx-10^8\ (\ll0).$$

$3600$ 这点偏置在 $10^8$ 面前微不足道，有效特征值仍是约 $-10^8$——偏置救不回来，局部 Hessian 依旧不定。一个数量级的对照就把「偏置非万能」钉死了：偏置的大小是固定的 $\frac{m}{h^2}=3600$，而负特征值随刚度 $k$ 线性放大，刚度一硬就压过偏置。下面这条 warn 就是这一现象的结论。

这组数是为讲解构造的自洽示例

$k=100\to\lambda_\perp=-100$、偏置 $3600\to$ 有效 $3500$、$k=10^8\to$ 有效 $\approx-10^8$ 全部可拿计算器复算；但绝对量级会随单位与条件数 $\kappa$ 缩放，关键是符号与「谁压过谁」的趋势——压缩→负特征值、偏置固定而负值随 $k$ 放大。取值沿用全书共享参数集（$h=1/60$、$m=1$、$k\in\{100,10^8\}$）。

偏置不是万能的，当前 C++ 也没有步长保护

当弹簧极硬（$k=10^8$）而质量很轻、或时间步偏大时，$\frac{m_i}{h^2}$ 可能压不住 $k(1-l_0/l)$ 的负，局部 $\mathbf H_i$ 仍可能不定。当前 TinyVBD C++ 的 solve() 直接执行 h.colPivHouseholderQr().solve(f)，随后用 vertex += dx 接受局部 full step；代码里没有 determinant guard、line search/能量验收或 modified/PSD Hessian。它在示例参数下经验上常能工作，但这不构成 raw step 单调下降定理。稳健优化器可用 modified/PSD Hessian 先修正非下降方向，再用 line search 控制步长；trust region 则可联合限制模型与步长。

这一节你要带走的

三句话：(1) 一根 Hookean 弹簧 $E=\tfrac12 k(l-l_0)^2$，力 $\mathbf f=k\frac{l_0-l}{l}\mathbf d$；能量 Hessian 是 gradient 的 Jacobian，也是 force Jacobian 的负号。(2) Hessian 只有轴向 $k$ 与横向 $k(1-l_0/l)$ 两个 distinct eigenvalues，3D 横向重数为 2；受压时的负横向曲率只是屈曲分析的局部原料。(3) 惯性项 $\frac{m}{h^2}\mathbf I$ 提供正偏置但不保证正定；当前 C++ 使用未经 line search/PSD 保护的 QR full step，不能据此宣称 raw step 单调。
